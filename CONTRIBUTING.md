# Como contribuir

1. Abra uma issue descrevendo a melhoria ou o problema, se ainda não existir.
2. Faça um fork e crie uma branch com nome claro.
3. Mantenha a demo sem dependências desnecessárias e preserve contraste, foco e responsividade.
4. Teste a página em largura móvel e desktop. Para mudanças Android, compile o app em Android Studio.
5. Envie um pull request explicando o que mudou e como testar.

Evite apresentar o projeto como produto oficial da Google. Ao adicionar imagens de terceiros, confira licença e atribuição; prefira screenshots criadas a partir deste projeto.
