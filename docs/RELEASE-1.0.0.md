Primeira versão estável do **m3 kit**, um starter independente Material 3 para web e Android.

### Novidades
- Identidade vetorial própria, laboratório de temas e interface editorial responsiva.
- Paletas reais Material Color Utilities, imagem local, copiar CSS, tabs por teclado e diálogo validado.
- Android com tema e idioma persistentes, Dynamic Color e fallback verde.
- Showcase completo e exemplo mínimo nas duas plataformas.

### Baixe conforme o uso
- **web-ready.zip**: site compilado pronto para hospedagem estática.
- **opensource-complete.zip**: fontes completas MIT.
- **web-source.zip / android-source.zip**: fontes por plataforma.
- **web-example.zip / android-example.zip**: exemplos com ambiente de build.
- **android-complete-debug.apk / android-example-debug.apk**: instaláveis de demonstração assinados com chave debug, não binários de produção.
- **SHA256SUMS.txt**: checksums de integridade.

Tudo é open source MIT; não há edição proprietária. Os APKs são de teste e podem exigir desinstalação ao trocar o build por diferença de assinatura debug.

### Validação automática exigida
Build web, testes Chromium, npm audit (high), build dos dois APKs e Android lint. Não houve certificação de acessibilidade, teste em aparelhos físicos ou publicação na Play Store. O escopo estável é o starter, não o catálogo completo de Material 3 nem um produto com backend.
