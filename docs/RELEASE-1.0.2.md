# m3 kit 1.0.2

## Novidades

- Catálogo interativo de Material Web 2.5.0 com os 43 módulos estáveis, imports individuais, busca, cores da marca e claro/escuro.
- Botões, ícones, FABs, chips, seletores, campos, listas, abas, menus/submenus, diálogo, sliders, progresso, elevação, foco e ripple reais.
- Exemplo mínimo oficial de botão + campo, separado do laboratório CSS autoral.
- Android: abas formulário/lista, campos, prioridade por menu, DatePicker, TimePicker, modal bottom sheet e tooltips em Explorar.
- README com badges reais, recursos navegáveis, quick start, personalização, downloads e cobertura por plataforma.
- Avisos e licenças de dependências incluídos no build e nos pacotes relevantes.
- Testes automatizados adicionais para registro de componentes, interação, tema, busca, exemplo mínimo e responsividade.

## Continuidade

Laboratório, tradução pt/en/es, extração local de cores, seleção conectada, galeria e exemplos anteriores foram preservados. O catálogo novo está em português. Releases 1.0.0 e 1.0.1 não são alteradas.

## Limites e distribuição

Este release é um starter demonstrativo, sem backend, login, pagamentos, agendamento ou dados reais. Os 43 módulos incluem containers/primitivos e não equivalem a todo Material 3/Expressive. Material Web está em manutenção. O fork foi usado como referência; a integração usa o pacote oficial fixado 2.5.0.

Código próprio MIT; dependências com licenças preservadas, Material Web Apache-2.0. Projeto independente, sem endosso da Google.

APKs são debug para instalação manual, assinados com chave de desenvolvimento. Não são binários de Play Store e podem exigir desinstalar versões anteriores. Verifique integridade em SHA256SUMS.txt. Publicação automática somente após build/testes web, auditoria, build Android e lint concluírem com sucesso.
