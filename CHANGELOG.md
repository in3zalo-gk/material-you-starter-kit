# Changelog

## 1.0.1

- Seleção conectada: fundo preenchido que desliza entre botões na web e no Android.
- Ripple no ponto clicado na web e ripple nativo no Android.
- Galeria web interativa com prévias fictícias, movimento configurável e elevação.
- README com ilustração animada e acesso direto à galeria.
- Testes de movimento intermediário, teclado, idiomas, resize e movimento reduzido.
- Exemplo web redistribuível inclui todos os módulos e estilos necessários.
- APKs com versionName 1.0.1 e versionCode 2.

## 1.0.0

- Identidade m3 kit: monograma vetorial verde, layout editorial e superfícies semânticas.
- Web: temas persistentes, extração local de paleta, cópia CSS, reset, tabs acessíveis, diálogo validado e idiomas pt/en/es.
- Vite atualizado para corrigir vulnerabilidade de dependência; lockfile incluído.
- Android: temas e idioma persistentes, Dynamic Color com fallback, estado preservado e app mínimo separado.
- Pacotes por plataforma, fontes MIT, exemplos, APKs debug e checksums.
- Release condicionada a build, testes web, auditoria e Android lint/build.
